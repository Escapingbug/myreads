# 推荐与简单听书（0.3.12）

无障碍模式以继续听书和发现下一本为主要流程：

- 进入时自动继续上次听的书，从原章节/段落恢复；已在播放时不重启。没有记录或上一部已经听完时直接展示推荐。
- 推荐每次介绍一本，包含书名、作者和简介。“就听这本”自动获取目录、准备要听的章节并开播；“换一本”继续浏览，不要求搜索或手动下载。“听简介”可重听完整介绍。
- 播放页只保留暂停/继续、换一本和更多功能。书架、搜索、历史、换段、章节与语速放在更多功能中。
- 准备时可以返回或换一本；被取消任务的迟到结果不会触发自动播放。当前章节提交后即可开始，剩余内容继续下载；网络失败时可直接重试或换书。
- 普通模式的书架也显示推荐卡片，点击后使用原有详情/下载流程。

## 数据与兼容

推荐来自启用的书源，不依赖新部署的服务端或个性化推荐模型。内置全本书源读取首页“推荐小说”，演示书源提供三篇原创短文。真实书源优先；回退演示时显示“纸间演示”来源。

API 1 书源可增加可选能力：

```json
{ "capabilities": ["recommend"] }
```

声明能力的脚本提供 `async recommend()`，返回与搜索相同的 `{ items: SourceBook[] }` 结构。无需实现能力的旧书源仍可正常搜索、下载和阅读。首页书目缺简介时按需使用已有 `getBook` 获取，不阻止用户直接开听或换书。

推荐每个来源最多缓存 60 本，缓存有效期 24 小时。失效后刷新失败时保留旧书单；完整书籍简介也会保存。缓存不表示正文已下载，离线时新书仍可能无法开始听。

换书会记住浏览位置和跳过的书，尽量不重复刚刚跳过的内容；当前书单全部看过后循环。此行为是本机浏览顺序，不是基于用户画像的个性化推荐。

已有安装只升级脚本 SHA-256 与原版完全一致的 1.0.0 内置书源，保留启用状态。用户修改/导入的脚本不会被覆盖；已有下载的书源快照保持不变。

## 验证边界

主机测试覆盖缓存、选择、内置升级、自动恢复、下载准备与取消、旧书源兼容；浏览器检查真实书源推荐/简介和小屏布局。浏览器音频夹具仅模拟播放状态。Android 听书效果、实体设备上的语音提示时延和连续播放仍需真机确认。所有构建与发布验证禁止使用模拟器或 ADB。
