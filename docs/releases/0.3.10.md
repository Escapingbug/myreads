# 纸间 0.3.10

语音无障碍模式改为单击按钮直接执行、长按听说明。长按后松手不会执行操作，无需先听按钮说明再双击。

- 书架、最近读听和搜索结果左滑下一本、右滑上一本；换书后自动播报书名、作者和进度，长按中间按钮听简介。原来的上一本、下一本按钮仍可单击使用。
- 最近搜索和章节列表也支持左右滑动。各列表的主要操作按钮统一放在状态卡片下方。
- 播放页单击中间按钮暂停或继续，左右滑动切换段落。暂停、继续和页内换段不再等待操作提示语音。
- 每页右上角明确显示「退出无障碍模式／协助者单击此处」，单击进入确认页，再单击确认恢复普通界面。取消回到原页面，书籍与阅读进度保留。
- 返回和帮助固定在底部，小屏幕可上下滚动中间操作区。进入页面时语音说明当前操作；首次设置仍由协助者完成，开启前必须实际加载本地语音模型。

可直接覆盖安装，无需重新下载模型。
