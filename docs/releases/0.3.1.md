纸间 0.3.1

- 改进听书长句分段：48 字作为参考长度，允许完整句子或分句延伸到约 72 字，减少句子中途被切开后重新起调的情况；英文优先在单词边界切分。
- 暂停听书同时挂起声音生成，在当前推理步骤完成后释放合成唤醒锁；继续播放时接着生成，停止时取消合成并释放模型。
- 减少推理线程空转和暂停后的状态刷新；已有音频缓存可直接播放，遇到未生成的片段才加载模型。
- 长句意外达到音频长度上限时，自动拆成更小的片段重新生成，避免播放截断的声音。

继续使用现有 MOSS-TTS-Nano 模型，无需重新下载。断句调整可以减少分段引起的语调重置，模型自行判断的重音和语气仍可能不准确。实时生成声音仍比播放普通音频更耗电；实体手机的耗电量取决于机型和使用情况。

0.3.0 用户可在「设置 → 检查更新」下载并覆盖安装，书架、阅读记录和已下载模型会保留。支持 Android 7.0 及以上，arm64-v8a / x86_64；模型不包含在 APK 中。
