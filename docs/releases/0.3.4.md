纸间 0.3.4

- 新增语音无障碍模式，无需开启 TalkBack。由协助者在「设置 → 语音无障碍模式」完成首次配置，下载并校验现有语音模型；每次进入模式必须实际加载模型成功。
- 使用超大按钮和语音说明操作：触摸或移动手指听按钮名称，抬手选中，在屏幕任意位置双击执行。底部固定返回和帮助，退出模式需要确认。
- 首页支持继续上次、最近读听、我的书架和找新书。书架、历史、搜索结果一次浏览一本，可听书籍简介、选择章节、切换段落及调整语速。
- 支持语音输入书名或作者，读回识别内容后确认搜索；可切换书源和复用最近搜索。请协助者先配置麦克风权限并测试手机的中文语音识别服务，识别服务可能需要联网。
- 最近读听记录独立保存，删除本地书籍后仍保留；重新下载时恢复匹配章节的进度，并优先下载上次读听的章节。
- 操作提示和正文共用一套本地 MOSS 模型，重复提示使用缓存；播报时暂停正文，结束后按播放意图恢复，用户主动暂停会保持暂停。调整驻留推理的临时内存管理。

从 0.3.3 覆盖更新会保留书架、阅读进度和已下载的模型，无需重新下载模型。模型仍在 App 内由用户主动下载，不包含在 APK 中。

已通过 87 项自动化测试及 Android 模拟器验证。首次语音提示合成需要等待，具体响应速度、语音识别和长时间使用体验请在实体手机试用后反馈。
