# 纸间 0.3.11

新增 Gitee 国内下载和应用更新渠道，保留 GitHub 备用。

- 应用更新默认自动检查两边正式版本，同版本优先从 Gitee 下载；连接失败时自动尝试同一安装包的另一个来源，支持断点续传。也可以在「设置 → 应用更新」手动选择来源。
- 两边版本不同会选择较新版本；只有版本、大小和 SHA-256 一致的安装包才能互相续传，安装前继续校验签名。
- 听书模型下载新增「自动（国内镜像优先）」，失败后尝试官方 Hugging Face。旧版保存过的下载来源会保留，可手动切换为自动。
- 小型语音活动检测文件随 APK 提供，首次准备模型时无需再从 GitHub 下载该文件。大型听书模型仍单独下载。

沿用原签名，可直接覆盖安装，保留书架、阅读进度和已下载模型，无需卸载或重新下载模型。

国内下载：https://gitee.com/anciety/myreads/releases/latest

GitHub 备用：https://github.com/Escapingbug/myreads/releases/latest
