# 纸间 0.3.15

正式听书切换至此前试听的 Audio8 Realistic Air 模型，支持中文及中英混读，正文与语音提示使用同一音色。

- 保留模型自然生成的语速、标点停顿和气口，支持原有倍速、后台播放与声音缓存。
- 默认边生成边播放，也可选择先准备本章；暂停同时挂起生成，已有缓存可直接播放。
- 下载支持断点续传和完整性校验；新模型与旧声音缓存隔离，避免复用不兼容资源。

沿用原签名，可覆盖安装，保留书架和阅读进度。升级后需在「听书」下载新的模型，约 1.16 GB；首次加载还会生成权重缓存，建议使用 Wi-Fi 并预留至少 2 GB 可用空间。旧模型不能用于新引擎。

已按项目发布流程进行主机测试和 APK 静态验证。实体手机上的持续生成速度、耗电、发热和后台表现尚未实测，生成跟不上播放时仍可能等待下一段。
