纸间 0.3.0

- 接入 GitHub Release 更新：打开应用时每天自动检查，也可在右上角「设置 → 检查更新」手动检查。
- 应用内下载 APK，支持后台下载、暂停和断点续传；完成后按 Android 提示确认安装。
- 安装前校验 SHA-256、应用包名、版本和签名，覆盖更新保留书架、阅读进度及已下载听书模型。
- 包含 0.2.1 的听书标点修复：省略号、引号、破折号和重复标点只转换听书输入，小说原文不变。

首次安装这版后，后续版本即可从 App 内更新。现有 0.2.x 用户请下载 zijian-0.3.0.apk，直接覆盖安装，无需卸载。

支持 Android 7.0 及以上，arm64-v8a / x86_64。听书模型不包含在 APK 中，在「听书」页按需下载（约 684 MiB）。
