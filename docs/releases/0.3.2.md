纸间 0.3.2

- 同一段内接续上一句的文字和语音，减少每次分段后重新起调；段落、章节和跳转重新锚定所选声音。
- 保留完整句、段落和对白结构，短对白与“她轻声问”等叙述尽量一起生成；过长句子优先在分句边界拆分，达到生成上限时自动缩小并重试。
- 检测音频首尾语音边界，结合句号、疑问、省略号、段落和章节调整衔接停顿，保留句内停顿和边界保护余量。
- 按可播放时长缓冲。自动模式检测到生成较慢时先准备本章，完成后开始播放；听书页可选择“边生成边播放”或“先准备本章”，并显示准备进度。
- 音频缓存同时保存语音上下文；顺序生成复用有界解码状态，准备完成后释放模型。App、系统媒体和锁屏暂停均会挂起推理，继续时接着生成。

更新后进入「听书」点击「继续下载」，补充约 **1.6 MiB** 的流式解码与语音检测文件。已有 MOSS 模型会复用，无需重新下载约 684 MiB 的旧文件；完整模型约 686 MiB，仍不包含在 APK 中。

先准备本章需要等待，生成较慢的手机在章节之间仍可能等待；边生成边播放在生成跟不上时仍可能停顿。重音和语气仍由模型判断，本地生成仍比普通音频播放更耗电。已验证自动化测试和 Android 模拟器，实体手机的长篇听感及耗电仍需实际试听确认。

0.3.0 / 0.3.1 用户可在「设置 → 检查更新」覆盖安装，书架、阅读记录和已下载模型会保留。支持 Android 7.0 及以上，arm64-v8a / x86_64。
