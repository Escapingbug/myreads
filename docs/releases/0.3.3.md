纸间 0.3.3

- 修正引号对白被拆成许多短请求的问题：保留完整对白及嵌套引号内容，过短句子合并为有界语组；长对白优先在完整句边界分开，内部标点交给模型处理。
- 所有语组统一使用所选声音的官方固定参考，取消段落处的生成模式切换和逐句传递声音，减少段落间的音色变化。
- 调整模型结束标记的选择，避免随机提前结束导致后半句漏读；声音本身仍采用采样生成。达到时长上限时仍会缩小语组重试。
- 加强句首、句尾保护：语音检测之外检查波形，只裁剪接近零的边缘样本；首次播放保留启动时间。旧算法生成的音频缓存会自动重新生成。

从 0.3.2 更新无需重新下载模型。模型仍由用户在 App 内点击下载，书架、小说正文和阅读进度保留。

已验证自动化测试、模型对照样例和 Android 模拟器。重音、语气及发音仍受模型影响，具体小说和实体手机的听感仍需实际试听。长篇准备方式、后台播放和暂停时挂起生成继续保留。
