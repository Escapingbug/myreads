# 纸间 0.3.12

无障碍听书更简单：进入接着听，想换故事看推荐。

- 进入无障碍模式自动继续上次的书，恢复原章节和段落；没有记录或上一本已听完时介绍推荐。
- 推荐页每次介绍一本书，喜欢点“就听这本”，应用自动准备章节后开始播放；不感兴趣点“换一本”，无需先搜索、加入书架或手动操作下载。
- 简单播放页保留暂停/继续、换一本和更多功能。书架、搜索、历史、章节和语速放进“更多功能”，退出和帮助始终可见。
- 普通书架也增加推荐书籍。推荐来自书源首页，书单和简介保存在本机；网络不稳定时仍能浏览已保存的推荐，新书正文仍需联网下载。
- 无障碍搜书增加输入框、书源选择和可修改的语音输入；搜索结果直接显示书名、作者及翻页，普通模式与无障碍模式共用搜索逻辑。搜索不再等待提示语音播完，失败与空结果也会显示在页面上。
- 改善锁屏后恢复阅读：保存阅读位置，恢复布局和重绘，增加渲染界面异常退出后的恢复处理。
- 调整无障碍模式在小屏、横屏和放大文字下的布局，避免常用操作被挤到屏幕外。
- 内置书源增加推荐能力，自动升级未被用户修改过的原版内置书源，保留启用状态；用户修改的书源及已有下载快照不会被覆盖。

沿用原签名，可覆盖安装，保留书架、阅读进度与已下载模型，无需卸载或重新下载模型。
